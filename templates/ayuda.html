    {{ icono("sin-red") }} Si no hay señal

      {% call paso(1, "nube", "Guarda igual") %}

      Verás una franja que dice «Sin conexión». Lo que guardes queda en tu teléfono.

      {{ icono("nube") }} 1 pendiente
      {% endcall %} {% call paso(2, "reloj", "Espera la señal") %}

      Cuando vuelva internet, se envía solo. El aviso de pendientes desaparece cuando todo llegó.

      {% endcall %} {% call paso(3, "alerta", "Si un registro dice «Rechazado»") %}

      Toca el aviso de pendientes, revisa el error y corrige los datos. No lo vuelvas a escribir desde cero.

      {% endcall %}

    Corregir un error

      {% call paso(1, "lotes", "Abre el lote") %}

      En «Lotes», toca «Ver y editar».

      {% endcall %} {% call paso(2, "check", "Cambia el dato y escribe el motivo") %}

      Por ejemplo: «el predio estaba mal escrito». El cambio queda guardado con tu nombre y la fecha.

      {% endcall %} {% call paso(3, "basura", "Si los kilos o una venta están mal") %}

      Toca «Anular» en esa fila y explica por qué. Nada se borra: queda tachado en el historial. Después registra el dato correcto.

      {% endcall %}

    Vender y revisar

      {% call paso(1, "ventas", "Anota la venta") %}

      En «Ventas», elige el lote, escribe el comprador, los kilos y el precio por kilo. La app no deja vender más de lo que tienes.

      {% endcall %} {% call paso(2, "qr", "Muestra el origen") %}

      Quien escanee el QR de la caja ve de dónde viene tu cosecha, sin precios ni ventas.

      {% endcall %} {% call paso(3, "imprimir", "Descarga el reporte") %}

      En el lote, toca «Descargar PDF» para auditorías.

      {% endcall %} {% call paso(4, "chispa", "Pide una recomendación") %}

      En «Trazabilidad» o «Clima». Es una sugerencia: revisa los datos que usó antes de hacerle caso.

      {% endcall %}
